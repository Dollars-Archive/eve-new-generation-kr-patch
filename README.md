## 게임 소개

**EVE new generation**은 2006년 PlayStation 2로 발매된 EVE 시리즈의 멀티사이트 미스터리 어드벤처 게임입니다.

사립탐정 **아마기 코지로**는 기억을 잃었다는 정체불명의 소녀에게 기억을 찾아 달라는 의뢰를 받습니다. 비슷한 시각, 내각정보조사실의 **호조 마리나**는 빌딩 옥상에서 한 청년의 투신을 목격하고 그의 손바닥에서 수수께끼의 **벌 문신**을 발견합니다.

서로 별개의 사건처럼 보였던 두 사람의 수사는 수도권 대정전, 무장 테러, 의문의 제약회사, 기억상실과 벌 문신을 따라 점차 하나의 사건으로 수렴합니다.

### 작품 특징

- 코지로 / 마리나 2인 주인공의 **멀티사이트 시스템**을 계승합니다.
- `Ever17`, `극한탈출` 시리즈로 잘 알려진 **우치코시 코타로**가 기획·원안·각본을 담당했습니다.
- 멀티사이트를 단순한 정보 분산뿐 아니라 **서술 트릭과 미스리드**에 적극적으로 활용합니다.
- EVE 후속작의 복잡한 설정 의존도를 비교적 낮추고, 코지로와 마리나 중심의 독립 사건에 가까운 구성을 취합니다.
- 초반에 배치한 복선들이 중후반에 연쇄적으로 회수되며 전개가 여러 차례 뒤집히는 것이 특징입니다.

보다 자세한 작품 소개와 발굴 자료는 **[Dollars Archive 게임 소개 페이지](https://dollars-archive.github.io/Game-Localization-Discovery-Archive/game.html?file=platforms%2Fps2%2Fgames%2Feve-new-generation.md)**에서 확인할 수 있습니다.
